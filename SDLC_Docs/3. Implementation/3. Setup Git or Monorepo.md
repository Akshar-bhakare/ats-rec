# **Monorepo & Git Setup**

---

## **A. Repository Structure**

**Recommended Root Layout:**

```plaintext
root/
  backend/          # NestJS API & workers (multi-tenant, all modules)
  frontend/         # React + Vite + MUI app (all portals, SPA)
  infra/            # Terraform, Kubernetes, IaC, backup/monitoring scripts
  scripts/          # Utility scripts (seed, migration, smoke-test, dev tools)
  SDLC_Docs/        # Project docs, planning, user stories, architecture
  .github/          # GitHub Actions, issue templates, PR templates
  .env.example      # Sample env vars (no secrets!)
  .gitignore
  README.md
  package.json      # For monorepo-level scripts (optional)
  nx.json           # Nx workspace config (if using Nx)
  tsconfig.base.json # Shared TS config (if using TS in both ends)
```

---

## **B. Initial Git Setup**

1. **Create empty repo (GitHub, GitLab, etc.)**

   ```bash
   git init
   git remote add origin git@github.com:yourorg/yourrepo.git
   ```

2. **Add folders:**

   ```bash
   mkdir backend frontend infra scripts SDLC_Docs
   ```

3. **Add `.gitignore`:**

   ```
   node_modules/
   dist/
   .env*
   coverage/
   .DS_Store
   *.log
   .next/
   ```

4. **Add README.md:**

   * High-level project overview
   * Table of contents for monorepo structure

---

## **C. Nx Monorepo (Optional, Recommended)**

* **Install Nx:**

  ```bash
  npx create-nx-workspace@latest aiselekt
  # Choose "empty", then add apps/libs for backend/frontend as needed
  ```

* **Add NestJS backend:**

  ```bash
  nx g @nrwl/nest:application backend
  ```

* **Add React frontend:**

  ```bash
  nx g @nrwl/react:application frontend
  ```

* **Workspace benefits:**

  * Consistent scripts for build, test, lint, format across all code
  * Shared linting, prettier, testing config
  * Fast CI, parallel builds, dependency graphs

---

## **D. Branching & Collaboration**

* **Branch protection:**

  * main/master protected (review required for PR)
  * Feature branches: `feature/`, `bugfix/`, `chore/`
* **Commit format:**

  * Conventional commits recommended (`feat:`, `fix:`, etc.)
* **Code reviews:**

  * All PRs require review by at least 1 developer

---

## **E. Example Scripts in Root `package.json` (if not using Nx)**

```json
{
  "scripts": {
    "start:backend": "cd backend && npm run start:dev",
    "start:frontend": "cd frontend && npm run dev",
    "lint": "eslint . --ext .ts,.tsx,.js,.jsx",
    "format": "prettier --write .",
    "test": "npm run test --workspaces"
  }
}
```
