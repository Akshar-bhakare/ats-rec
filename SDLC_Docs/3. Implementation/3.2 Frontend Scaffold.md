## **A. Directory Structure**

```plaintext
frontend/
  src/
    components/        # Shared UI components (buttons, table, modal, etc.)
    pages/             # Route-based views (Dashboard, Login, Jobs, etc.)
    routes/            # Route definitions
    hooks/             # Custom hooks
    services/          # API calls, auth, etc.
    stores/            # Global state (Zustand/Redux or Context)
    theme/             # MUI theme config, palette, typography
    assets/            # Images, logos
    App.tsx            # App root, routing
    main.tsx           # Entry point (Vite)
  public/              # Static files
  .env                 # Frontend env vars
  vite.config.ts
  package.json
  tsconfig.json
```

## **B. Install and Initialize**

```bash
cd frontend
npm create vite@latest . -- --template react-ts
```

```typescript
const theme = createTheme({
  palette: {
```

## **D. App Root & Routing (src/App.tsx)**

```typescript
import { ThemeProvider, CssBaseline } from '@mui/material';
import { BrowserRouter, Routes, Route, Navigate } from 'react-router-dom';
import theme from './theme/theme';
import LoginPage from './pages/LoginPage';
import DashboardPage from './pages/DashboardPage';
import JobsPage from './pages/JobsPage';
import NotFoundPage from './pages/NotFoundPage';

function App() {
  return (
    <ThemeProvider theme={theme}>
      <CssBaseline />
      <BrowserRouter>
        <Routes>
          <Route path="/login" element={<LoginPage />} />
          <Route path="/dashboard" element={<DashboardPage />} />
          <Route path="/jobs" element={<JobsPage />} />
          <Route path="/" element={<Navigate to="/dashboard" />} />
          <Route path="*" element={<NotFoundPage />} />
        </Routes>
      </BrowserRouter>
    </ThemeProvider>
  );
}
export default App;
```

## **G. Getting Started**

1. **Install dependencies:**
   `npm install`
2. **Set env vars:**
   `.env` with `VITE_API_BASE_URL=https://yourapi.com/api/v1`
3. **Run dev server:**
   `npm run dev`
4. **Open:**
   [http://localhost:5173](http://localhost:5173)

## **H. MUI Design Tips**

* Use `@mui/material` for layout, forms, buttons, navigation.
* Leverage MUI [Figma Kit](https://mui.com/store/items/figma-react/) for design handoff.
* Organize shared components (`Button`, `Table`, `Drawer`) for re-use.
* Responsive design: Use `Grid`/`Box` and MUI breakpoints.
