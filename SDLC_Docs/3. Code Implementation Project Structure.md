## **2. Backend (NestJS + MongoDB) Scaffolding**

**A. Scaffold the project:**

```bash
# Install Nest CLI globally if you don’t have it
npm i -g @nestjs/cli

# Create new project
nest new backend

# Add and configure MongoDB (Mongoose)
cd backend
npm install @nestjs/mongoose mongoose
```

**B. Example module generation:**

```bash
nest generate module jobs
nest generate controller jobs
nest generate service jobs
# Repeat for users, campaigns, etc.
```

**C. Example MongoDB config in NestJS**

```typescript
// app.module.ts
import { MongooseModule } from '@nestjs/mongoose';

@Module({
  imports: [
    MongooseModule.forRoot(process.env.MONGODB_URI || 'mongodb://localhost:27017/ai-recruitment'),
    // ...your modules
  ],
  // ...
})
export class AppModule {}
```

**D. Sample Mongoose Schema for Job:**

```typescript
import { Prop, Schema, SchemaFactory } from '@nestjs/mongoose';
import { Document } from 'mongoose';

@Schema()
export class Job extends Document {
  @Prop({ required: true, index: true })
  tenantId: string;

  @Prop()
  title: string;

  @Prop()
  description: string;

  @Prop()
  recruiterId: string;

  @Prop()
  status: string;

  @Prop({ default: Date.now })
  createdAt: Date;
}

export const JobSchema = SchemaFactory.createForClass(Job);
```

import axios from 'axios';
const API = '/api/v1/jobs';

export const getJobs = async (params = {}) =>
  axios.get(API, { params }).then(res => res.data);

export const createJob = async (data) =>
  axios.post(API, data).then(res => res.data);

## **4. Docker & Dev Environments**

**Sample `docker-compose.yml`:**

```yaml
version: "3.9"
services:
  mongo:
    image: mongo:6
    ports:
      - "27017:27017"
    volumes:
      - ./data/mongo:/data/db
  backend:
    build: ./backend
    ports:
      - "5000:5000"
    environment:
      - MONGODB_URI=mongodb://mongo:27017/ai-recruitment
    depends_on:
      - mongo
  frontend:
    build: ./frontend
    ports:
      - "3000:3000"
    environment:
      - VITE_API_URL=http://localhost:5000/api
    depends_on:
      - backend
```
