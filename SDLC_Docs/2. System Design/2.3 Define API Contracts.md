## **A. General Guidelines**

* **All endpoints are tenant-aware.**

  * Tenant resolved via subdomain, JWT claim, or `X-Tenant-Code` header.
* **All endpoints secured by JWT + RBAC middleware.**
* **OpenAPI (Swagger) spec generated from code** (NestJS/TypeScript decorators).
* **Standard error format:**

  ```json
  {
    "statusCode": 400,
    "error": "Bad Request",
    "message": "Field X is required"
  }
  ```

## **C. Sample OpenAPI Spec (YAML) — Interview Scheduling & Feedback**

```yaml
openapi: 3.0.1
info:
  title: Interview Service API
  version: 1.0.0
servers:
  - url: https://{tenant}.yourapp.com/api/v1
paths:
  /interviews:
    post:
      summary: Schedule an interview
      tags: [Interviews]
      requestBody:
        required: true
        content:
          application/json:
            schema:
              type: object
              properties:
                jobId: { type: string }
                candidateId: { type: string }
                scheduledAt: { type: string, format: date-time }
                panelists: { type: array, items: { type: string } }
      responses:
        '201':
          description: Interview scheduled
          content:
            application/json:
              schema:
                $ref: '#/components/schemas/Interview'
  /interviews/{id}/reschedule:
    patch:
      summary: Reschedule interview (Panelist/Recruiter)
      tags: [Interviews]
      parameters:
        - in: path
          name: id
          schema: { type: string }
          required: true
      requestBody:
        required: true
        content:
          application/json:
            schema:
              type: object
              properties:
                newTime: { type: string, format: date-time }
      responses:
        '200':
          description: Interview rescheduled
  /interviews/{id}/join:
    post:
      summary: Join interview session (Panelist/Recruiter)
      tags: [Interviews]
      parameters:
        - in: path
          name: id
          schema: { type: string }
          required: true
      responses:
        '200':
          description: Session joined
  /feedback:
    post:
      summary: Submit feedback after interview (Panelist)
      tags: [Feedback]
      requestBody:
        required: true
        content:
          application/json:
            schema:
              type: object
              properties:
                interviewId: { type: string }
                ratings:
                  type: object
                  additionalProperties: { type: integer }
                comments: { type: string }
                recommendation:
                  type: string
                  enum: [pass, fail, maybe]
      responses:
        '201':
          description: Feedback submitted
components:
  schemas:
    Interview:
      type: object
      properties:
        _id: { type: string }
        jobId: { type: string }
        candidateId: { type: string }
        scheduledAt: { type: string, format: date-time }
        panelists: { type: array, items: { type: string } }
        status: { type: string }
        feedback: { type: array, items: { type: string } }
```

## **D. Notes & Best Practices**

* **All endpoints are prefixed by `/api/v1/` and require tenant context.**
* **Role-based RBAC enforced at endpoint and business logic layers.**
* **Comprehensive OpenAPI spec generated, maintained in codebase.**
* **Panelist (Interviewer) endpoints are locked down:**

  * Can only view/join/reschedule/submit feedback for interviews assigned to them.
  * Cannot access unrelated jobs/candidates.
