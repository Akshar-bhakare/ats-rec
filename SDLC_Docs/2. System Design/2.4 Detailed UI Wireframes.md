# **Detailed UI Wireframes: AISelekt Multi-Tenant Platform**

---

## **A. UltraAdmin**

**1. Login & Two-Factor Auth**

* Email/password fields
* 2FA modal (if enabled)

**2. System Dashboard**

* Metrics cards (Active Tenants, Credits, Errors, API Usage)
* Tenants table (name, status, admins, actions)
* “Create Tenant” modal

**3. Tenant Management**

* Tenant detail view (profile, admin list, settings)
* Invite/assign ClientAdmin modal

**4. Audit Logs & Alerts**

* Filterable log table
* Error alerts drawer

---

## **B. ClientAdmin**

**1. Login**

* Same as above

**2. Client Dashboard**

* Metrics: Active jobs, candidates, recruiters, credits
* Stats cards, quick links to create job/campaign
* Credit usage & alerts

**3. Recruiter Management**

* Recruiter list, add/edit modal
* Role assignment dropdown

**4. Company Profile**

* Editable form, logo uploader

**5. Communication Settings**

* Tabs for WhatsApp, Email templates
* Template list, create/edit modal (rich text, variables)

**6. Job Management**

* Job list/table (search, filter, actions)
* “Create Job” stepper modal (Details, Screening, Stages, Preview)
* Job detail (tabs: Overview, Candidates, Insights, Activity Log)

---

## **C. Recruiter**

**1. Login/Dashboard**

* Jobs summary, interviews scheduled, action items
* Quick links: Create job, Add candidate, Start campaign

**2. Job Board**

* Search/filter, status badges, pipeline view
* Job detail (tabs: Overview, Candidates, Activity)

**3. Candidate Management**

* Candidate list/table, filter bar
* “Add Candidate” modal, resume upload, bulk import stepper
* Candidate profile page (Summary, Resume/Skills, Interview History, Communications)

**4. Interview Scheduling**

* Schedule AI/manual interview wizard (candidate, panelists, time)
* Calendar integration (date picker, time slots)

**5. Campaign Management**

* Campaign list, create campaign wizard (job, candidates, script, voice settings)

---

## **D. Agency**

**1. Login/Dashboard**

* Submissions this month, active clients, status badges
* Client/job assignment list

**2. Candidate Submission**

* Submission form: select job, candidate, upload resume
* Submission tracker (status, feedback)

**3. Reports**

* Filters for client/date/job
* Conversion rate, placements, export CSV

---

## **E. Candidate**

**1. Registration Wizard**

* Stepper: Personal info, resume upload, terms
* Profile completion meter

**2. Candidate Dashboard**

* Applications list, recommended jobs, interview invites
* Profile quick edit, resume update

**3. Job Search & Apply**

* Job cards, search/filter sidebar
* Job details (JD, requirements, apply button)

**4. Application Tracker**

* Application status timeline
* Interview schedule (calendar, reschedule if allowed)

**5. AI Assessment / Coding Test**

* Embedded code editor (Monaco/MUI TextField), timer
* Video interview UI (record, submit, review)

---

## **F. Interviewer (Panelist)**

**1. Interviewer Dashboard**

* Assigned interviews (table/list: candidate, job, time, status)
* Tabs: Upcoming, Pending Feedback, Completed
* Calendar mini-view

**2. Interview Detail**

* Candidate info, resume, job description
* Join Interview button (if session open)
* Reschedule button (calendar picker/modal)
* Status badge (scheduled, rescheduled, completed)

**3. Feedback Form**

* Ratings (MUI Slider/Stars), comments (MUI TextField), pass/fail radio
* Submit/Save Draft buttons
* Feedback history (read-only for completed interviews)

---

## **G. General/Shared Components**

* **Top Navigation Bar:** Logo, user avatar, notifications, help
* **Sidebar:** Role-based, collapsible, icons + labels
* **Modals/Drawers:** For create/edit/view actions, full-screen on mobile
* **Tables/Lists:** MUI DataGrid/List for all major entities
* **Search/Filters:** MUI Autocomplete, date pickers, chips for active filters
* **Toast Notifications:** Success/error messages, snackbars
* **Responsive Design:** Mobile-first breakpoints, card views for tables on mobile
