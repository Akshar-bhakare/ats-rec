## **UltraAdmin**

### **Day in the Life**

* Starts by logging into the system dashboard.
* Checks platform health metrics, recent incidents, and usage analytics.
* Reviews any critical alerts or notifications (API limits, failed integrations, credits low).
* Adds a new client (tenant) as requested by business team; allocates initial credits.
* Reviews platform-wide communication templates, updates system-wide announcements.
* Responds to a support escalation: temporarily pauses a client for investigation.
* Approves new integration keys for a client.
* Exports a monthly compliance and usage report for finance/legal.

### **Key User Journeys**

1. **Login & System Health Monitoring**

   * Login → Dashboard (global stats, health, alerts) → Click into alerts for details → Dismiss or escalate as needed.

2. **Onboard New Client**

   * “Add Client” → Enter company details → Assign ClientAdmin → Set credit/quota → Send welcome email → View client listed.

3. **Emergency Actions**

   * System Alert triggered (e.g., API abuse) → Pause affected client(s) → Notify ClientAdmin → Resume after issue resolved.

4. **Audit & Compliance**

   * Open Compliance Reports → Filter by date/client → Export CSV/PDF → Share with relevant teams.

5. **Manage Global Integrations**

   * Navigate to Integrations → Add new API key/provider → Update settings → Test and confirm connectivity.

## **ClientAdmin**

### **Day in the Life**

* Logs in and reviews company dashboard (jobs, candidates, recruiter performance, credits).
* Notices open jobs need more candidates; invites a new recruiter.
* Configures a new WhatsApp reminder template for candidates.
* Approves two new job postings created by recruiters.
* Reviews credit usage; sees credits low, requests top-up from UltraAdmin.
* Assigns a new job to an approved agency partner.
* Downloads performance report for management.

### **Key User Journeys**

1. **Recruiter Onboarding**

   * Dashboard → “Invite Recruiter” → Enter details → Assign permissions → Send invite → Track onboarding status.

2. **Job Management**

   * Jobs → Create/Edit Job → Fill job form (with dynamic autocomplete) → Save as draft or publish → Approve recruiter submissions.

3. **Communication Template Management**

   * Settings → Communication Templates → Edit WhatsApp/Email templates → Preview & Save → Set active/inactive.

4. **Assign Agency to Job**

   * Jobs → Select job → Agencies tab → Assign agency from approved list → Agency notified.

5. **Monitor Credits & Usage**

   * Dashboard → Credits widget → View history → Request more credits.

---

## **Recruiter**

### **Day in the Life**

* Logs in, sees assigned jobs and their pipeline stages.
* Bulk uploads new candidates for a high-priority job.
* Searches Databank for good-fit candidates using advanced filters and tags.
* Schedules AI interviews for top candidates; customizes script per job.
* Communicates with candidates (email/WhatsApp) to confirm availability.
* Reviews AI interview transcripts and shortlists candidates for next round.
* Updates candidate statuses, adds notes, and notifies the hiring manager.
* Prepares shortlist to export/send to ClientAdmin for review.

### **Key User Journeys**

1. **Bulk Import Candidates**

   * Candidates → Import → Upload CSV/Resumes → Map fields → Preview/import → Resolve duplicates.

2. **Candidate Search & Pipeline Progression**

   * Databank → Apply filters/tags → Select candidates → Move through stages (screening, interview, offer).

3. **Schedule AI Interview**

   * Candidate profile → “Schedule AI Interview” → Select template & time → Send invitation.

4. **Candidate Communication**

   * Candidate record → Email/WhatsApp tab → Select template → Send → Log communication.

5. **Status Update & Shortlisting**

   * Candidates → Update status (shortlisted/rejected) → Add notes → Export shortlist for manager.

---

## **Agency**

### **Day in the Life**

* Logs in to agency portal; sees jobs assigned by client.
* Prepares and bulk uploads candidates for current open roles.
* Tracks each submission status (pending, reviewed, selected, rejected).
* Receives notification that a candidate is scheduled for AI interview.
* Downloads feedback or status updates from client portal.
* Responds to a client comment or request for updated CV on a submission.
* Runs a report to track monthly placement numbers.

### **Key User Journeys**

1. **Submit Candidates to Client Jobs**

   * Dashboard → View assigned jobs → “Add Submission” → Enter/select candidate → Upload resume/cover note → Submit.

2. **Track Submissions**

   * Submissions tab → Status table → Filter by status/job/date → View status and feedback.

3. **Bulk Upload Candidates**

   * Dashboard → “Bulk Upload” → Upload file → Map fields → Import.

4. **Download Feedback & Reports**

   * Submissions → View feedback/comments → Download CSV of placements/stats.

5. **Notification Handling**

   * Receive email/WhatsApp for submission status changes → Login for details/action.

---

## **Candidate**

### **Day in the Life**

* Receives invitation (email/WhatsApp) to register/apply for a job.
* Clicks link, completes profile with resume upload, skills, preferences.
* Searches for jobs, applies for one or more positions.
* Receives AI interview invite, schedules/joins at a suitable time.
* Participates in AI or manual interview, receives real-time feedback.
* Tracks progress of all applications and interview results via dashboard.
* Receives offer/feedback; accepts or requests more info.

### **Key User Journeys**

1. **Registration & Profile Setup**

   * Invitation link → Registration form (multi-step: info, resume, consent) → Set password → Complete profile (skills, preferences).

2. **Apply to Jobs**

   * Dashboard → Search/Filter jobs → Review details → Apply → Confirmation.

3. **Schedule/Join AI Interview**

   * Dashboard/Email → “Join Interview” link → Review instructions → Start interview (phone/video/assessment).

4. **Track Application Status**

   * Dashboard → Application tracker → View status (under review, interview scheduled, offer, rejected).

5. **Receive & Review Feedback**

   * Dashboard/Email → Feedback notification → View summary/next steps.

## **Interviewer (Panelist)**

### **Day in the Life**

* Receives an interview assignment notification via email or calendar invite.
* Clicks the invite link to access the Interviewer Dashboard (no need for full login if link/OTP provided).
* Reviews list of all assigned interviews, including upcoming, completed, and any pending feedback.
* Opens an upcoming interview to view candidate profile, resume, and job description.
* Realizes a scheduling conflict and clicks “Reschedule” to propose a new interview time.
* Confirmation shown; candidate and recruiter are notified of the change.
* Joins the interview at the scheduled (or rescheduled) time via “Join Interview” link.
* Conducts the interview, referring to structured evaluation criteria and feedback prompts.
* Immediately after, fills out the feedback form: ratings, notes, pass/fail recommendation.
* Dashboard updates to show interview as “Completed” and feedback as “Submitted.”
* Optionally, reviews history of interviews and feedback for reference.
* Logs out; no further action required until next assignment.

---

### **Key User Journeys**

1. **Access Dashboard & Upcoming Interviews**

   * Click invite link (or log in) → Arrive at Interviewer Dashboard → See all assigned interviews sorted by status (upcoming, pending feedback, completed).
2. **Review Candidate & Interview Details**

   * Select an interview → View candidate profile, resume, and job details → Prepare for session.
3. **Reschedule Interview**

   * Identify scheduling conflict → Click “Reschedule” on interview → Select new date/time (calendar picker) → Confirm → System notifies all parties and updates schedule.
4. **Join and Conduct Interview**

   * At scheduled time, click “Join Interview” → Launch video/AI/manual session → Conduct interview.
5. **Submit Feedback**

   * After interview, click “Submit Feedback” → Complete structured form (ratings, notes, pass/fail) → Submit → Dashboard reflects completion.
6. **View Interview History**

   * From dashboard, access “Completed Interviews” → Review feedback history and details for personal reference.
