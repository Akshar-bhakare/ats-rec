## **Non-Functional Requirements**

### **1. Performance**

* **Response Time:**

  * All API calls (CRUD, search) should complete in <500ms under normal load.
  * Real-time actions (AI call audio, WebSocket messages) must have <2s end-to-end latency.
* **Concurrency:**

  * Support at least 200 concurrent active users per tenant and 1000 total across all tenants without degradation.
* **Bulk Operations:**

  * Import/export of up to 10,000 candidates per action should complete within 3 minutes.
* **Search:**

  * Global and filtered search results should return in <2 seconds.

### **2. Scalability**

* **Horizontal Scaling:**

  * Backend and WebSocket services must scale horizontally (Kubernetes pods or similar).
  * Support “n” number of tenants, each with isolated MongoDB database.
* **Elasticity:**

  * System must autoscale on cloud based on CPU/memory/queue depth.
* **Database Growth:**

  * Each tenant DB supports up to 100,000 candidates and 10,000 jobs without manual tuning.
* **Integration Scaling:**

  * Third-party API calls (Plivo, Google STT/TTS, OpenAI) must handle spikes with internal rate-limiting and retry/backoff logic.

### **3. Security**

* **Authentication & Authorization:**

  * Use JWT-based auth with strong password/2FA for all users.
  * RBAC enforced at API, service, and UI layers (per-tenant, per-role).
* **Multi-Tenancy Isolation:**

  * Hard isolation between tenant databases; no cross-tenant data access.
  * All resource access must require tenant context via subdomain/header/JWT claims.
* **Data Encryption:**

  * All PII and sensitive data encrypted at rest (MongoDB encryption) and in transit (TLS 1.2+).
* **Input Validation:**

  * All user input sanitized and validated (backend and frontend).
* **Audit Logs:**

  * Log all sensitive operations (login, permission changes, data exports).
* **Vulnerability Management:**

  * Weekly dependency scans (Snyk/npm audit), regular penetration tests before each major release.
* **Session Management:**

  * Token expiry, single sign-on, and session revocation supported.

### **4. Compliance**

* **GDPR/CCPA Ready:**

  * User consent and privacy statements required at registration.
  * Data export and “right to be forgotten” endpoints for candidates.
  * Data retention and deletion policies documented per client.
* **Auditability:**

  * Downloadable audit logs for all admin actions.
  * All data changes (creation, update, delete) timestamped and tracked per user.
* **Access Controls:**

  * Only authorized personnel can access client data or system settings (no shared accounts).
* **PII Handling:**

  * All candidate/user data access controlled, masked in logs, not shared outside tenant.
* **Data Residency:**

  * Deployments configurable to run in specific regions (India, EU, US) to comply with local regulations.

### **5. Availability & Reliability**

* **Uptime:**

  * 99.9% uptime for production environments.
  * Automated failover and redundancy for critical services.
* **Disaster Recovery:**

  * Nightly backups for each tenant DB; restore tested monthly.
  * RTO (Recovery Time Objective) ≤ 4 hours; RPO (Recovery Point Objective) ≤ 15 minutes.
* **Monitoring & Alerting:**

  * Real-time monitoring for all core services (API, WebSocket, DB, external APIs).
  * Alerts for downtime, error spikes, failed jobs, high queue depth.
* **Graceful Degradation:**

  * If third-party APIs (AI, STT/TTS, telephony) are down, users are notified and can retry/fallback to manual workflow.

### **6. Maintainability**

* **Code Quality:**

  * 80%+ code coverage with automated tests.
  * Consistent code style, linting, and documentation enforced in CI.
* **DevOps:**

  * Automated deployment pipeline; rollback on failed releases.
  * Infrastructure as Code (Terraform/Helm) for all environments.
* **Documentation:**

  * Up-to-date API docs, onboarding guides, runbooks for operations.

### **7. Usability & Accessibility**

* **Responsive Design:**

  * Fully functional across mobile, tablet, and desktop.
* **Accessibility:**

  * Meets WCAG 2.1 AA standards (keyboard nav, contrast, ARIA labels).
* **Localization:**

  * UI text and notifications easily translatable; support for at least English/Hindi in MVP.
