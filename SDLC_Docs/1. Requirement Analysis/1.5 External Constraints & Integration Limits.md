### **General Integration Constraints**

* **Network Latency/Timeouts:**

  * All outbound API calls must have a timeout (≤10s) and graceful error handling.
* **Legal/Privacy:**

  * Consent required for storing/transmitting user voice, candidate data to 3rd parties.
* **Data Residency:**

  * Some clients may require data be stored/processed only in certain regions (India, EU, US).

---

### **Recommendations for Handling Constraints**

* Always **monitor API usage** and **rate limit** at your app level.
* **Alert users/admins** when quotas are nearing limits.
* Design for **retry and fallback**—e.g., if OpenAI is overloaded, use an alternate model or fallback to manual flow.
* **Document all API credentials, quotas, and usage patterns** per tenant in your admin dashboard.
