Absolutely! Here’s a **prioritized, role-based user story backlog** for your multi-tenant recruitment platform, covering all main features. Each story uses the “As a \[persona], I want to \[do something], so that \[goal/benefit]” format, and includes **acceptance criteria**.

---

## **User Story Backlog**

---

### **UltraAdmin**

**1. Onboard New Client (Tenant)**

* **User Story:**
  As an UltraAdmin, I want to create a new client with its own admin, so that each organization has its own secure workspace.
* **Acceptance Criteria:**

  * Must be able to add/edit/suspend/delete clients.
  * On creation, system generates new tenant DB and admin user.
  * Client receives welcome email with credentials.
  * Client appears in the global client list.

**2. Allocate Credits to Clients**

* **User Story:**
  As an UltraAdmin, I want to allocate and adjust credits for each client, so that resource usage is controlled and monitored.
* **Acceptance Criteria:**

  * Can assign credits during client creation or later.
  * UI displays current usage and alerts at thresholds.
  * Credits deducted in real-time for calls/AI usage.

**3. View Platform Health and Logs**

* **User Story:**
  As an UltraAdmin, I want to see global metrics, alerts, and logs, so I can monitor platform health and respond quickly to incidents.
* **Acceptance Criteria:**

  * Dashboard shows live stats (usage, errors, API limits).
  * Filter logs by client, time, event type.
  * Receive and dismiss critical alerts.

---

### **ClientAdmin**

**4. Manage Company Profile**

* **User Story:**
  As a ClientAdmin, I want to update company details, logo, and settings, so that our organization information is accurate and branded.
* **Acceptance Criteria:**

  * Can edit all company info fields.
  * Logo upload/preview available.
  * Changes are reflected immediately to all users.

**5. Invite and Manage Recruiters**

* **User Story:**
  As a ClientAdmin, I want to invite new recruiters and manage their permissions, so my team can manage jobs and candidates effectively.
* **Acceptance Criteria:**

  * Invite via email, assign roles.
  * View/edit/disable recruiter accounts.
  * Recruiters cannot see data from other clients.

**6. Assign Agencies to Jobs**

* **User Story:**
  As a ClientAdmin, I want to assign specific jobs to approved agencies, so only authorized agencies can submit candidates.
* **Acceptance Criteria:**

  * Can select agencies for each job.
  * Agencies only see assigned jobs and submissions.
  * Removal disables further submissions from that agency.

**7. Configure Communication Templates**

* **User Story:**
  As a ClientAdmin, I want to edit WhatsApp and email templates for our workflows, so communications fit our brand and process.
* **Acceptance Criteria:**

  * Can create/edit/delete templates.
  * Preview before saving.
  * Assign templates to triggers (e.g., interview invite, offer).

**8. Monitor Credits and Usage**

* **User Story:**
  As a ClientAdmin, I want to view our credit usage and receive alerts, so I can avoid disruptions.
* **Acceptance Criteria:**

  * Credits widget shows live usage.
  * Alerts at 80%, 90%, 100% usage.
  * Option to request top-up from UltraAdmin.

---

### **Recruiter**

**9. Create and Manage Jobs**

* **User Story:**
  As a Recruiter, I want to create, edit, and publish jobs, so I can attract candidates for open roles.
* **Acceptance Criteria:**

  * Can create/edit/save jobs as drafts or publish.
  * Only job type and work mode are dropdowns; others use autocomplete fields.
  * Published jobs are instantly searchable.

**10. Add and Search Candidates**

* **User Story:**
  As a Recruiter, I want to add, bulk import, and search candidates, so I can efficiently manage the talent pipeline.
* **Acceptance Criteria:**

  * Add candidates via form, upload resume, or bulk CSV.
  * Typeahead/autocomplete for fields (skills, location, etc.).
  * Search/filter candidates with advanced options.

**11. Schedule AI Interviews**

* **User Story:**
  As a Recruiter, I want to schedule AI phone or video interviews for candidates, so I can screen at scale.
* **Acceptance Criteria:**

  * Select candidates, choose template, schedule date/time.
  * System sends invite and reminders.
  * Interview status and results visible in candidate profile.

**12. Advance Candidates Through Stages**

* **User Story:**
  As a Recruiter, I want to move candidates through stages (screening, interview, offer), so I can track their progress.
* **Acceptance Criteria:**

  * Drag-and-drop or action buttons to change stage.
  * Status changes are logged and visible to all authorized users.
  * Optional notes per status change.

**13. Communicate with Candidates**

* **User Story:**
  As a Recruiter, I want to send WhatsApp/email messages to candidates from within the platform, so communication is centralized.
* **Acceptance Criteria:**

  * Can select candidate(s), choose template, send.
  * Logs of sent communications visible in candidate timeline.
  * Fallback to alternate channel if preferred one fails.

---

### **Agency**

**14. Submit Candidates for Assigned Jobs**

* **User Story:**
  As an Agency user, I want to submit new candidates for jobs I’ve been assigned, so I can support clients’ hiring.
* **Acceptance Criteria:**

  * Only see jobs assigned to agency.
  * Add single or bulk candidates.
  * Each submission requires minimum fields (name, contact, resume).

**15. Track Submission Status**

* **User Story:**
  As an Agency user, I want to see the status of all my candidate submissions, so I know which are under review, selected, or rejected.
* **Acceptance Criteria:**

  * Dashboard shows status per submission (pending, reviewed, selected, rejected, placed).
  * Filters/search for date, job, status.
  * Notification of status changes.

**16. Download Feedback and Reports**

* **User Story:**
  As an Agency user, I want to download feedback and monthly stats, so I can report placement success to my management.
* **Acceptance Criteria:**

  * Export report as CSV/Excel.
  * Filter by client, job, date.
  * View/download per-candidate feedback.

---
### **Interviewer (Panelist)**

**1. Access Assigned Interviews Dashboard**

* **User Story:**
  As an Interviewer, I want to access a dashboard listing all interviews assigned to me, so that I can easily see what interviews I need to conduct and which require feedback.

* **Acceptance Criteria:**

  * Can access dashboard via secure invite link or login.
  * Dashboard shows only interviews assigned to the Interviewer, sorted by status (upcoming, completed, pending feedback).
  * Each interview shows candidate name, job title, date/time, and feedback status.

---

**2. Review Candidate and Job Details**

* **User Story:**
  As an Interviewer, I want to view the candidate’s profile, resume, and job description before an interview, so that I can prepare relevant questions and evaluations.

* **Acceptance Criteria:**

  * Can access candidate profile and resume from interview details.
  * Job title, description, and requirements are shown.
  * Cannot see other candidates, jobs, or any unrelated data.

---

**3. Reschedule an Interview**

* **User Story:**
  As an Interviewer, I want to reschedule an assigned interview if I have a conflict, so that the interview can be conducted at a mutually convenient time.

* **Acceptance Criteria:**

  * “Reschedule” option is available for upcoming interviews.
  * Can select a new date/time within allowed scheduling windows.
  * System notifies candidate, recruiter, and other panelists of the change.
  * Rescheduling is only possible before the interview has started.

---

**4. Join Interview Session**

* **User Story:**
  As an Interviewer, I want to join the interview session directly from the dashboard at the scheduled time, so that I can conduct the interview without extra navigation.

* **Acceptance Criteria:**

  * “Join Interview” button is visible for each upcoming interview at the correct time.
  * Session launches in a new tab or modal.
  * Handles scenarios where session is not started, or already expired, with clear messages.

---

**5. Submit Interview Feedback**

* **User Story:**
  As an Interviewer, I want to fill out and submit a structured feedback form after each interview, so that my evaluation is recorded and shared with the recruiter or hiring team.

* **Acceptance Criteria:**

  * Feedback form appears immediately after interview is marked as completed.
  * Form includes required fields (ratings, comments, pass/fail, notes).
  * Can only submit one feedback per interview (editable until final submission).
  * Submitting feedback updates interview status to “Feedback Submitted.”

---

**6. View Interview and Feedback History**

* **User Story:**
  As an Interviewer, I want to view my past interviews and feedback submissions, so that I can reference my previous evaluations and participation.

* **Acceptance Criteria:**

  * Dashboard includes a section for “Completed Interviews” with access to previous feedback forms.
  * Feedback is read-only after submission deadline.
  * Cannot access or edit interviews not assigned to them.


---

### **Candidate**

**17. Register and Complete Profile**

* **User Story:**
  As a Candidate, I want to register, upload my resume, and set my preferences, so I can apply to jobs easily.
* **Acceptance Criteria:**

  * Register via link/invite, complete multi-step profile.
  * Upload resume and auto-parse fields.
  * Consent checkbox and data privacy statement.

**18. Search and Apply to Jobs**

* **User Story:**
  As a Candidate, I want to search for jobs and apply in one click, so I can maximize my opportunities.
* **Acceptance Criteria:**

  * Search/filter jobs (typeahead for skills/location).
  * Apply with saved profile; confirmation toast/email.
  * Application tracked in dashboard.

**19. Schedule/Attend AI Interview**

* **User Story:**
  As a Candidate, I want to schedule or attend an AI interview from my dashboard or invite, so I can move forward in the hiring process.
* **Acceptance Criteria:**

  * See available interview times or immediate start.
  * Join via link or phone; see instructions.
  * Upon completion, receive feedback or next step info.

**20. Track Application Status and Feedback**

* **User Story:**
  As a Candidate, I want to track my application status and receive feedback, so I know where I stand and what’s next.
* **Acceptance Criteria:**

  * Dashboard shows status per job.
  * Notifications for interview, rejection, offer, or next steps.
  * Feedback view with next-step guidance.

## **Prioritization (MVP Focus)**

* **Must Have:**
  Client onboarding, user/candidate/job management, AI interview scheduling, submission tracking, communications, basic analytics, core agency/candidate flows.
* **Should Have:**
  Bulk imports/exports, template management, credit dashboards, detailed reporting, fallback communications.
* **Could Have:**
  Advanced analytics, native mobile app, deep ATS integration, custom workflows, bulk feedback.
